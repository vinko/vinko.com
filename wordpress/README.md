# Version 1 — original WordPress public mirror

This directory is the **Version 1** archive of the public vinko.com WordPress site.

```
www.vinko.com/       # WordPress blog “Vinko’s Thoughts On…” (HTML + public assets + uploads)
hosting.vinko.com/   # public hosting.vinko.com pages
vinko.com/           # apex host (redirects to www)
```

Photos live under `www.vinko.com/wp-content/uploads/`.

This is a public crawl snapshot, not a deployable WordPress install. Full PHP from hosting is optional later. Do not deploy to ICDSoft / live vinko.com without confirmation.

Spelling: **Vinko** / **vinko.com**.
