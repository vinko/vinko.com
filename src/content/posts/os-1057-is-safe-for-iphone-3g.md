![Pwnage Tool logo](/wp-content/uploads/2009/07/pineapple.png)Apple released the new [OS X update 10.5.7](http://blog.vinko.com/2009/05/13/how-to-apply-os-x-update-1057/ "Best Procedure for Updating OS X") on Tuesday evening (US PST). When it was released most users with unlocked iPhone 3G were worry that the latest OS X update will further hamper their Mac’s ability to place the iPhone into DFU mode.

Now the iPhone Dev Team has [tweeted](http://twitter.com/iphone_dev/status/1792809382 "iPhone Dev Team tweet") yesterday that OS 10.5.7 is even more compatible to the jailbreak process than OS 10.5.6, which disabled the DFU mode.

> The new 10.5.7 Leopard update is safe. In fact it’s more jailbreak-friendly than 10.5.6, since the DFU-mode bug is gone.

So I now recommend everyone to upgrade your Mac OS 10.5 as soon as possible, as there are many security fixes in OS 10.5.7, including a [Safari 4 Beta security update](http://support.apple.com/kb/HT3551 "Safari 4 Beta security update release notes") that you only see after upgrading to OS 10.5.7.
