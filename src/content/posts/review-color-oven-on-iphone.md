[![Color Oven Logo](/wp-content/uploads/2009/08/color-oven-logo.png)](/wp-content/uploads/2009/08/color-oven-logo.png)I came across this designer tool called, “Color Oven” by Lima’s Web Design, they also have an OS X version of the application for USD2.99.

![color-oven1](/wp-content/uploads/2009/08/color-oven1.png)

The purpose of this application is quite straight forward. You choose a color and the application will generate a set of complimentary colour schemes: monochromatic, complimentary, analogous, or triad, for you.

This application’s features are not unlike many of the web based colour scheme generators, like [ColorSchemeDesigner.com](http://colorschemedesigner.com/). Web site like Colr.org will accept a photo from Flickr or uploaded from the user’s computer, to generate a complimentary colour scheme from it.

[![Color Oven - Schemes](/wp-content/uploads/2009/08/color-oven2.png)](/wp-content/uploads/2009/08/color-oven2.png)I would not call myself a designer, but I do appreciate design, and I do often build web sites. For this application to be useful to me, I would need the ability to manually enters the HEX (preferred) or RGB codes for the desire colour then have the application generate the colour scheme.

This iPhone application is [available on iTunes](http://click.linksynergy.com/fs-bin/stat?id=AYDmH5A9AOI&offerid=146261&type=3&subid=0&tmpid=1826&RD_PARM1=http%253A%252F%252Fitunes.apple.com%252FWebObjects%252FMZStore.woa%252Fwa%252FviewSoftware%253Fid%253D323623290%2526mt%253D8%2526uo%253D6%2526partnerId%253D30) for USD1.99; 1 dollar less than the OS X version, I think they are both too much to ask for when ColorSchemeDeisgner can do the same thing for free.
