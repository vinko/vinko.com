[![Mac OS 10.6.4 Update](/wp-content/uploads/2010/06/screen-shot-2010-06-16-at-22-07-15.png)](http://support.apple.com/kb/DL1048)  
As promised Apple just made available [Mac OS 10.6.4](http://support.apple.com/kb/DL1048) for download.

There are two Knowledge Base articles to describe what have changed in this latest OS X release. The first is “[About the Mac OS X v10.6.4 Update](http://support.apple.com/kb/HT4150)” and the other is an “[About the security content of Security Update 2010-004 / Mac OS X v10.6.4](http://support.apple.com/kb/HT4188)“.

As with all other OS X updates I recommend that you download the [Combo Update](http://support.apple.com/downloads/DL1048/en_US/MacOSXUpdCombo10.6.4.dmg "OS 10.6.4 Combo Updater") and then apply it to your Mac.
