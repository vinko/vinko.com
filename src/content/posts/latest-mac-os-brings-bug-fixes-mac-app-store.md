![Mac OS 10.6.6 Upgrade Screen](/wp-content/uploads/2011/01/screen-shot-2011-01-06-at-21-51-45.png)Aside from the list of fixes the latest version of the Mac OS X ([v 10.6.6](http://support.apple.com/kb/DL1349)) finally enables the highly anticipated Mac App Store. You can either get the update from Apple Software Update or you can download the Combo Updater from [Apple’s Support site](http://support.apple.com/kb/DL1349).

You can read [Apple’s Knowledge Base article](http://support.apple.com/kb/HT4459) on the list of fixes.
