It appears that the features that Twitter staff had hinted about is appearing on the Twitter.com web site slowly.

I noticed now you can row your cursor over someone’s [@reply](http://twitter.com/vinko "Vinko on Twitter") reference, a tip box showing the individual’s profile will appear.  
[![twitter-profile-tip](/wp-content/uploads/2010/03/twitter-profile-tip.png)](/wp-content/uploads/2010/03/twitter-profile-tip.png)  
There is also a “more” link where you can expand the individual’s profile information to review his biography, number of tweets, followers and following.

[![twitter-profile-tip-more](/wp-content/uploads/2010/03/twitter-profile-tip-more.png)](/wp-content/uploads/2010/03/twitter-profile-tip-more.png)  
While the actions menu is still available at the bottom right of the popup window to allow the user to follow, un-follow, block and report the individual.  
[![twitter-profile-tip-actions](/wp-content/uploads/2010/03/twitter-profile-tip-actions.png)](/wp-content/uploads/2010/03/twitter-profile-tip-actions.png)  
I look forward to seeing what other features the Twitter team is cooking up.
