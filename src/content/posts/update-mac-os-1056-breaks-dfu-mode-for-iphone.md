The [iPhoneDev Team has released a note](http://blog.iphone-dev.org/post/65126957/tis-the-season-to-be-jolly) addressing the [issue reported](http://blog.vinko.com/2008/12/16/warning-mac-os-1056-breaks-hacked-iphone/) regarding the problem with activating the DFU (device firmware update) mode for the iPhone, after the Mac has been upgraded to Mac OS 10.5.6.

The next release of the iPhoneDev Team’s Pwnage Tool is not expected until Christmas Eve (Dec. 31.2008), but there is no mention if this upcoming release will resolve the DFU problem.
