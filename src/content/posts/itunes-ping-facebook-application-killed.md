When I signed onto [iTunes Ping](http://www.apple.com/itunes/ping/ "iTunes Ping") this morning (HK time) I was able to connect [my account](http://bit.ly/itunes-ping "Vinko on iTunes Ping") to my [Facebook](http://facebook.com/vinko "Vinko on Facebook") account to locate my Facebook friends who are already on Ping.

![Ping - Facebook Connect](/wp-content/uploads/2010/09/ping-facebook.png) ![Ping - Facebook Login](/wp-content/uploads/2010/09/ping-fb-login.png)Later on in the morning I start to encounter problems with the Facebook connection. It first thinks that I am no longer connected, then when I try to reconnect it has trouble reaching Facebook.

![Ping - Facebook Find Friends](/wp-content/uploads/2010/09/ping-fb-friends.png)After a few more attempts the Facebook Connect button on the Ping Home page in iTunes disappeared.

![Ping - Facebook Connect Missing](/wp-content/uploads/2010/09/ping-fb-missing.png)  
Did Apple kill the Ping Facebook application? Or did Facebook killed it because it stressed Facebook’s API infrastructure too much?
