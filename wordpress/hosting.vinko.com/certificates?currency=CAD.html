Certificate installation info
When installing the certificate on our server, you can have it installed on a dedicated IP address for your domain, or on a shared IP address using Server Name Indication (SNI).

The SNI technology is supported by all modern browsers and operating systems, but the certificate might not be displayed correctly on older and legacy systems such as Internet Explorer 8 on Windows XP and some older Androids.

The installation on a dedicated IP address involves an additional fee for the IP, which is paid depending on the duration of your plan.

If your goal is to replace an already installed certificate and its annual IP address fee is already paid, you do not need to submit the fee again.
